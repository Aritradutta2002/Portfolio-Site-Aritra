## Conventions learned
- Edit tool in this env can silently not apply — verify edits with Read after tricky changes (twice caught silently-unapplied edits).
- Build hangs if `next start` holds `.next`; kill server first or rm -rf .next.
- Builds: `npm run build` passes; only pre-existing warning is `GlassCard` unused in legacy src/components/Contact.tsx (left untouched).
- Prod smoke: `npx next start -p 3999`; curl needs `--noproxy` handling — proxy returns 502 for GET, node fetch works when server is a background task (dies if started with `(… &)`).
